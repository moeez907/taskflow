About TaskFlow

TaskFlow is a web-based task management application that lets you create, organize, and track your daily tasks in one place.

Purpose

The purpose of TaskFlow is to help users stay organized and productive. Whether you are managing school assignments, work items, or personal to-dos, TaskFlow gives you a simple way to record tasks, set priorities and due dates, and monitor what is still pending or already completed.

Navigation Guide

Use the navigation bar at the top of every page to move between sections. Each link takes you to a different part of the application:

Page What It Does
Home (Dashboard) The main landing page with a task summary and quick links to other pages.
Add Task A form for creating a new task with a title, description, due date, and priority.
Task List A table showing all tasks, with buttons to filter by All, Pending, or Completed.
Task Detail A focused view of a single task where you can read its full information.
About This page — an overview of the app, its purpose, and how to use it.

How to Use the App

Follow these steps to get started with TaskFlow:

Step Action
1 Open the Home page to see an overview of your tasks, including totals for pending and completed items.
2 Click Add Task in the navigation bar, fill in the task details, and submit the form to create a new task.
3 Go to Task List to view all your tasks. Use the All, Pending, or Completed filter buttons to narrow the list.
4 Select a task and open Task Detail to review its full title, description, due date, priority, and status.
5 Return to the Home page at any time using the navigation bar or the quick-link buttons on the dashboard.
